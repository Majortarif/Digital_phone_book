## ✨ Features

| | |
|---|---|
| 📝 **Create, View, Edit** | Full CRUD for every contact |
| 🔍 **Search** | Find by name, phone, email, company, address, or notes |
| 🗑️ **Remove** | Delete contacts, list re-syncs and re-saves automatically |
| 🚫 **Block / Unblock** | Hide contacts from the main list without deleting them |
| ⭐ **Favorites** | Mark and browse your most-used contacts separately |
| 📊 **Statistics Dashboard** | Breakdown by group and relationship, at a glance |
| 📤 **Export** | Write the whole book out to a clean, readable `.txt` file |
| 🎨 **Colorized UI** | Distinct colors for menus, success, and errors |
| ⌨️ **Animated Intro** | Typewriter title + loading spinner on startup and saves |

## 🖥️ Two Ways to Experience It

### 1. Original — C Console App
The real project: a from-scratch Contact Management System in C, built for
Windows console using `windows.h` / `conio.h`.

### 2. Bonus — Browser Version
A companion single-page version of the same phonebook, built in HTML/CSS/JS,
hosted live on GitHub Pages so anyone can try it with one click — no compiler
required. See the **Live Web Demo** link above.

## 🚀 How to Run (C Console App)

1. Clone this repository
   ```bash
   git clone https://github.com/Majortarif/REPO-NAME.git
   ```
2. Open the project in **Code::Blocks**
3. Make sure the active compiler is **MinGW GCC**
4. Build and Run (`F9`)
5. **Important:** delete any old `contact.txt` / `id.txt` in the project folder
   before the first run — the contact structure was updated, so old data
   files from the 2022 version aren't compatible
