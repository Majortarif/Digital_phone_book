# Digital Phonebook 2026

Modernized version of my original 2022 console phonebook project.  
A complete **Windows console-based Contact Management System** written in C.

---

## Features

- Create, View, Edit, Search & Remove contacts
- Block / Unblock contacts
- Mark contacts as Favorite
- Contact Statistics (by Group & Relationship)
- Export contacts to a readable `.txt` file
- Colorized console UI
- Typewriter title animation + loading spinner

---

## How to Run

1. Open the project in **Code::Blocks**
2. Make sure you are using **MinGW GCC** compiler
3. Build and Run the program
4. **Important:** Delete any old `contact.txt` and `id.txt` files before running for the first time (because the structure was updated)
